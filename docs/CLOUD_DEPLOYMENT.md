# Cloud deployment

This deploys RAYA as a single-user, always-on web app. The browser UI and FastAPI API run in one container; Groq provides model inference. In cloud mode, tools that open applications, access the host filesystem, inspect connected source folders, or control host hardware are not registered.

## Before deploying

- Revoke any Groq key that has been placed in `.env.example`, source control, or another shared file. Create a replacement and store it only as a secret in the hosting provider.
- Push the project to a private source repository. Check that no credentials are committed before pushing.
- Choose an always-on container plan. Sleeping/free instances do not meet an anytime availability requirement.
- Configure persistent storage mounted at `/app/data`. RAYA stores memory and its RAG index there. The app has no document-upload screen, so copy any knowledge files into `/app/data/knowledge` using the hosting provider's secure console or deployment workflow.

## Render setup

1. Push the project to GitHub, making sure `.env` is not committed and the replacement Groq key is not in the repository.
2. In Render, choose **New → Blueprint**, connect the GitHub repository, and select the branch you want to deploy.
3. Render reads `render.yaml`, creates an always-on Docker web service in Singapore, attaches persistent storage, and configures auto-deploy on commits to that branch.
4. When prompted, enter `RAYA_ACCESS_PASSWORD` and the replacement `GROQ_API_KEY`. `RAYA_SESSION_SECRET` is generated by Render. Never commit these values.
5. Wait for the first deploy to finish, then open the service's `onrender.com` HTTPS URL and sign in. Open that same URL on mobile.

The Blueprint sets these non-secret values for you:

| Variable | Value |
|----------|-------|
| `RAYA_CLOUD_MODE` | `true` |
| `RAYA_AUTH_ENABLED` | `true` |
| `RAYA_SESSION_SECRET` | Generated by Render |
| `RAYA_SESSION_MAX_AGE` | `604800` (7 days) |
| `LLM_PROVIDER` | `groq` |
| `GROQ_BASE_URL` | `https://api.groq.com/openai/v1` |
| `GROQ_MODEL` | `openai/gpt-oss-20b` or another model enabled for your account |
| `RAYA_RAG_ENABLED` | `false` unless you have populated persistent cloud knowledge data |

The Blueprint also prompts for the two secret values `RAYA_ACCESS_PASSWORD` and `GROQ_API_KEY`. The health-check path is `/api/auth/session`; this endpoint is intentionally reachable before login. Render supplies `PORT` and HTTPS termination.

## Limitations

- Creating the actual Render service and public URL still requires you to sign in to Render and connect your GitHub account; I cannot do that from this workspace.
- The cloud instance can use Groq, web search, cloud-persisted RAG, memory, and configured remote integrations. It cannot open apps, control volume, or access files on your powered-off laptop.
- HTTPS is required for browser microphone access. Mobile speech recognition support varies by browser; typed requests remain available.
- Keep the app behind its password login. Do not disable cloud authentication or publish the Groq key.
